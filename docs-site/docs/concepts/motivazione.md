# Motivazione

Laravel teams are adding LLMs, classifiers, ranking models, and autonomous workflows faster than compliance teams can manually inventory them. The package exists to make compliance evidence a normal part of application architecture.

## Problem

AI Act and GDPR obligations often span product, engineering, legal, security, and operations. Without durable records, teams rely on spreadsheets and incident memory.

## Design pressure

::: grids
  ::: grid
    ::: card "Transparency"
    Users need to know when they interact with AI or consume AI-generated output.
    :::
  :::
  ::: grid
    ::: card "Control"
    Teams need consent, review, and escalation gates close to the request path.
    :::
  :::
  ::: grid
    ::: card "Evidence"
    Auditors need dated records connected to controls, owners, and articles.
    :::
  :::
:::

## Outcome

The package gives Laravel applications first-class models and services for compliance workflows while keeping legal decisions in the organization that owns the system.
