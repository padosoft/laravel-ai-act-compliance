# Teoria

The package treats compliance as evidence-producing workflows. Each workflow links a subject, an actor, a decision, and a regulatory reason.

## Control equation

$$
Control\ quality = coverage \times timeliness \times traceability
$$

Coverage means the workflow applies to every relevant AI use case. Timeliness means records are created when decisions happen. Traceability means the record points back to a user, tenant, model workflow, article, or owner.

## Mapping

| Obligation style | Package primitive |
| --- | --- |
| Inform users | Disclosure middleware and Blade directive |
| Respect choices | Consent records |
| Classify systems | Risk register |
| Enable rights | DSAR service and contracts |
| Monitor behavior | Bias metric registry |
| Keep humans in loop | Human review tracker |
| Report failures | Incident tickets and transitions |

::: callout info "Theory in practice"
The package does not attempt to decide every legal question. It makes the evidence and state transitions explicit so expert review has reliable material.
:::
